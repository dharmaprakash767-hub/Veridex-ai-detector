# 🛡️ Veridex AI - AI Image Forensic Detector

Veridex AI is a light-weight forensic web tool that detects AI-generated images using deep learning models via the Sightengine API. Built with FastAPI for a rapid asynchronous backend and styled with a calm, editorial UI.

## ✨ Features
- 🔍 **AI Artifact Detection**: Identifies synthetic patterns from DALL-E, Midjourney, Stable Diffusion, and other popular image generators.
- ⚡ **Fast & Lightweight**: Asynchronous backend driven by FastAPI.
- 🎨 **Editorial UI**: Minimalist, evidence-led user experience.

## 🛠️ Tech Stack
- **Backend:** Python, FastAPI, Requests, Uvicorn
- **Frontend:** HTML5, CSS3 (Custom Properties), JavaScript (Fetch API)
- **API:** Sightengine AI Detection Engine
